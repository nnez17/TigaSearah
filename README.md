# Tiga Searah

Website studio berbasis Astro, Tailwind CSS v4, Three.js, GSAP, React, Nitro, Resend, dan Zod. Semua perintah proyek memakai **Bun 1.4.3**. Tidak ada data klien, harga, nama anggota, atau testimoni rekaan.

Tooling Astro memerlukan Node.js >=22.12.0; sesi ini memakai Node.js 26.10.0. Package manager dan server produksi memakai Bun.
